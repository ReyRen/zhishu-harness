# 统一模型设置

[English](README.md) | 中文

平台 Web profile 在**设置 → 模型设置**中管理模型，使用 Harness 原生组件提供类型筛选、卡片、搜索、编辑和连接测试。设计参考 gcs-webnora 的模型设置，页面直接挂载于现有设置外壳。对话、嵌入、重排、视觉和语音识别模型汇总为当前用户的一份可用目录，不按空间导航。新配置归属于该用户，各应用从同一目录选用模型，保留自己的默认选择和处理规则。已有记录保持原 ID 和来源权限；只读来源允许使用，不授予配置权限。已有文档索引保留原 Embedding 模型绑定。

内嵌知识库不再单独提供模型管理页。模型选择器通过当前 iframe 经来源校验的 `weknora:open-model-settings` 消息打开 Harness 设置，模型变更通过 `weknora:models-updated` 刷新目录，各应用自己的模型选择逻辑保持不变。知识库选择器让多个调用方共用一次认证，隔离各调用方的取消信号，并在目录返回 401 后重新领取一次 SSO 票据。

## 配置与执行

`WEKNORA_BASE_URL` 指定现有、经过认证的 gcs-webnora API，包含 `/api/v1`。Worker 提供 `DSH_PLATFORM_USER_ID`；认证使用当前用户的平台 SSO，令牌只保留在 Host 内存中。共享模型密钥或用户自行提供的身份不能替代该认证。原生页面调用经过所有者认证的 `/api/zhishu-models/manage` 操作，无需单独的模型页面地址。知识库页面使用独立的浏览器地址配置。

后端须提供 `GET /api/v1/models/available`，每次读取目录都重新核查成员权限。共享知识库仅授权执行该资源已绑定的模型，不会把所有者的其他模型或凭据加入用户目录。删除模型会核查所有应用和业务空间中的引用。

设置插件在切换分区时保留已加载的列表和未完成草稿，退出登录时清除列表及输入的密钥。已存凭据保持只写：输入框留空保留原值，明确清除时才删除，连接测试通过模型 ID 使用已存凭据。凭据更新失败会保留已提交的模型定义 ID，供重试使用。无法确认保存结果时，须关闭编辑框并刷新列表核对，再次创建前避免重复操作。已有嵌入模型的标识和维度在编辑器中保持固定，更换时需要新建模型并明确重建索引。

模型目录和凭据保留在 gcs-webnora 数据库中。Harness 通过注册的 `zhishu-models` 适配器调用经过空间授权的流式接口，由 gcs-webnora 解析凭据并访问指定的推理服务。这一层后端转发避免把已存密钥返回浏览器或用户容器，同时允许 Harness 容器停止后知识库后台任务继续运行。服务必须能在现场网络中访问。服务或模型接口不可用时，随包依赖不能代替模型推理。

模型选择保留 `<workspaceID>:<modelID>` 作为内部归属标识；目录按模型 ID 去重，不按名称合并。准备好的请求携带已存配置版本；配置被并发修改时会明确返回配置变更错误。适配器保留工具 JSON、绑定模型的推理状态及流式用量，拒绝不完整的响应和当前后端 API 不支持的显式停止序列。图片沿用已有的保留附件投影，请求体上限为 32 MiB。

## 已有 profile

平台 overlay 禁用旧内置提供方的配置页面和路由。运维人员通过 gcs-webnora 导入命令，把已有模型定义和凭据迁入各自经过验证的私有空间，不改变已有知识库绑定；完全相同的配置复用，连接不同的配置保留。生成的 `DSH_HOME/storages/zhishu-models/legacy-model-map.json` 不含凭据，记录 `version: 1`、`platformUserID` 和 `models` 条目（`provider`、`model`、`tenantID`、`id`）。Host 校验其归属，并优先使用这些精确别名，当前切换到其他空间时也一样。旧文件保留。仅配置在已停止用户 profile 中的模型也须在滚动更新前导入。

空闲会话使用已退役路由时，通过原生日志化模型选择 API 按导入映射、唯一匹配名称、唯一空间默认模型或唯一可用模型迁移。匹配不明确或映射中的模型已删除时需手动选择。正在使用的第三方适配器和已有统一模型选择保持不变。模型所有者独立于可选的知识库工具组合包加载。

## 验证

构建会运行[适配器测试](../../docker/tests/unified-models.test.mjs)、[原生管理测试](../../docker/tests/native-model-settings.test.mjs)及[真实 Web 组合烟测](../../docker/smoke-models.mjs)。烟测通过模拟后端认证隔离用户，通过原生管理保存配置，迁移旧模型选择，执行知识库工具，再完成下一轮模型调用；不访问外网或真实用户存储。该测试验证组合与协议行为，现场真实模型调用需单独检查。
