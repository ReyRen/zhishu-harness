# 检索前选择知识库

[English](guide.md) | 中文

## 变更

平台 WeKnora 适配层在用户选择知识库之前不开放工具。`WEKNORA_KNOWLEDGE_BASE_IDS` 限制可选范围，不再自动启用检索。适配层使用全新的限定范围 RAG 会话，拒绝自定义 Agent、复用后端会话和联网搜索。profile 自己持有的上游组合包独立运行。

## 迁移

1. 保留现有 SSO 和后端配置，无需迁移令牌。
2. 在会话输入框中输入 `/`，选择“知识库”，在原生下拉列表中勾选一个或多个可用知识库。每次更改立即生效，无需弹窗保存。新会话默认不选择；恢复和分支会话保留日志中的选择，已有单选保持选中。
3. 输入框保留一个入口：未选择时显示“知识库”，单选显示名称，多选显示“知识库 · 已选 N 个”。点击可重新打开同一下拉，不改变草稿和附件；搜索或切到“已选”查看完整名称。Tab 可访问筛选和清空控件，点列表外、Esc 或焦点离开时收起下拉。检索和文档读取限定在已选知识库内，调用前逐一核对访问权限；更改选择会中止正在进行的检索。
4. 清空全部选择或执行 `/knowledge off` 停用工具。已检索内容仍保留在历史上下文中，详见[平台插件说明](../../../../overlay/weknora/README.zh.md)。
