# 检索前选择知识库

[English](guide.md) | 中文

## 变更

平台 WeKnora 适配层在用户选择知识库之前不开放工具。`WEKNORA_KNOWLEDGE_BASE_IDS` 限制可选范围，不再自动启用检索。适配层使用全新的限定范围 RAG 会话，拒绝自定义 Agent、复用后端会话和联网搜索。profile 自己持有的上游组合包独立运行。

## 迁移

1. 保留现有 SSO 和后端配置，无需迁移令牌。
2. 在会话输入框中输入 `/`，选择“知识库”，勾选一个或多个可用知识库后保存。新会话默认不选择；恢复和分支会话保留日志中的选择，已有单选保持选中。
3. 确认输入框显示所有已选名称。检索和文档读取限定在这些知识库内，调用前逐一核对访问权限。点击取消放弃弹窗草稿；更改选择会中止正在进行的检索。
4. 点击取消或执行 `/knowledge off` 停用工具。已检索内容仍保留在历史上下文中，详见[平台插件说明](../../../../overlay/weknora/README.zh.md)。
