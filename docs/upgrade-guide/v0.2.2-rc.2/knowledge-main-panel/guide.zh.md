# 知识库面板

[English](guide.md) | 中文

## 变更

平台 Web 和 Desktop profile 从全局侧栏打开知识库，不再依赖已安装工作台。已有知识库工作台会话进入主会话列表；其他工作台归属、Session 日志、文件和笔记保持不变。知识库面板中的 AI 助手创建原生主会话。

## 迁移

1. 发布前按平台发布流程备份已有工作台状态。
2. 打开更新后的客户端。它仅移除旧知识库入口及其会话归属引用。加载或保存失败会保留可见错误并停止后续动作。
3. 确认主列表仍可访问历史知识库会话，其他工作台仍保留各自会话，知识库面板无需市场安装即可打开。
